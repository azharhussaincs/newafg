# Data Dictionary & Column Specification

## Dataset Overview
- **File Name:** `two.txt`
- **Encoding:** UTF-16 Little Endian (LE) with Byte Order Mark (`\xff\xfe`)
- **Format:** Comma-Separated Values (CSV)
- **Line Endings:** CRLF (`\r\n`)
- **Total Columns:** 16

---

| # | Column Name | Physical Data Type | Logical Type | Description & Domain Meaning | Observed Format / Examples |

## Semantic Guidance & Truth in Data
1. **Gender Interpretation:** Gender values are strictly preserved as recorded (`0` and `1`). Analysis tools clearly display observed raw values and standard semantic definitions.
2. **Calendar System:** `DoBYear` represents Solar Hijri years (e.g. 1388 SH corresponds approximately to 2009-2010 CE).
3. **Unicode Preservation:** All Dari/Persian characters are strictly preserved without lossy character replacement or transliteration corruption.
